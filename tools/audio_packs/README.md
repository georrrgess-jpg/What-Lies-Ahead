# Audio packs

Each `.py` file here is a sound pack generated by `tools/gen_audio.py`.
A pack imports the synthesis helpers and lists what to write:

```python
from gen_audio import *   # tone, sweep, noise, env, filt, band, place, silence, groan, blip, ...

def my_sound():
    return sweep(800, 200, 0.3, "saw") * env(0.3, 0.002, 0.2)

SOUNDS = [my_sound]                 # -> audio/sfx/my_sound.wav
VARIANTS = [(my_sound, (0.93, 1.07))]  # -> my_sound_b.wav, my_sound_c.wav (picked at random)
LOOPS = {"my_hum": lambda: ...}     # -> audio/sfx/my_hum.wav, seamless
MUSIC = {"my_world_loop": my_music} # -> audio/music/my_world_loop.ogg (stereo (n, 2) array)
```

Generate one pack: `python tools/gen_audio.py <pack_name>`. All: `python tools/gen_audio.py`.
Name sounds with a pack prefix (e.g. `neon_drone_hum`) so packs never collide.
