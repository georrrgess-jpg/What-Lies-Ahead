# UI style guide

The look of every menu and HUD element in *What Lies Ahead*: a **carnival arcade at
sunset**. Marquee signs with chasing light bulbs, riveted teal metal frames, cream-trimmed
signboards on dark aubergine, neon cyan and pink plates, chunky cream display lettering,
and 3D dioramas behind the panels. The target is `references/ui-arsenal-reference.png`.

Everything is built in code from one kit:

| What | Where |
| --- | --- |
| Entry point: palette, type scale, theme, one-line constructors | `scripts/ui/ui_kit.gd` (`UiKit`) |
| Components | `scripts/ui/kit/*.gd` |
| Materials (9-slice textures, icons) | `art/ui/*.png`, generated by `python3 tools/gen_ui_textures.py` |
| Texture names and 9-slice margins | `scripts/ui/kit/kit_tex.gd` (`KitTex`) |
| Motion | `scripts/ui/kit/ui_fx.gd` (`UiFx`) |
| Sounds | `scripts/ui/kit/ui_sound.gd` (`UiSound`), generated by `python3 tools/gen_audio.py ui` |
| The menu shell and the page contract | `scripts/ui/main_menu.gd`, `scripts/ui/menu_page.gd` |
| Every component on one screen | `--shot-scene=kit` (`scripts/ui/kit/kit_gallery.gd`) |

```bash
# Look at the whole kit (see scripts/dev/screenshot.gd for the launcher line):
... --resolution 960x540 -- --shot=/tmp/kit.png --shot-scene=kit
```

## Start a screen

```gdscript
func _ready() -> void:
	UiKit.apply(self)          # theme + mip-mapped texture filter, on the top Control only
```

`UiKit.apply()` gives plain `Button`, `PanelContainer`, `HSlider`, scrollbars and tooltips
the kit's look, so nothing on screen is ever unstyled. Children inherit it.

The canvas is **1920x1080**, stretched with `canvas_items` / `expand`: a 16:10 window is
1920x1200 and an ultrawide one is wider than 1920. Never position by absolute pixels from
the right or bottom edge; use anchors and containers. All sizes below are canvas pixels.

## Palette

| Constant | Hex | Use |
| --- | --- | --- |
| `UiKit.PINK` | `#ff3fa4` | The primary action, selection of toggles, "NEW" |
| `UiKit.CYAN` | `#35f0ff` | Selected card, active slot, section captions |
| `UiKit.AMBER` | `#ffc24a` | Warnings, locks, level, mastery, titles of dialogs |
| `UiKit.TEAL` / `UiKit.METAL` | `#17a3a3` / `#2b918c` | Secondary buttons, painted metal |
| `UiKit.CREAM` | `#fff3dc` | Sign lettering and body text on dark panels |
| `UiKit.MUTED` | `#b9add9` | Secondary text on dark panels |
| `UiKit.PANEL` | `#1d1338` | Signboard face |
| `UiKit.INK` / `UiKit.NAVY` | `#120c2e` / `#1b1446` | Text on bright chips, darkest fills |
| `UiKit.PURPLE` | `#6a34b8` | Neutral buttons, the off state of toggles |
| `UiKit.GREEN` / `UiKit.RED` | `#52f060` / `#ff4d6a` | Success / cannot afford, danger |
| `Wallet.COLOR` / `Wallet.COLOR_GLOW` | `#ffd84a` / `#38f0ff` | Sparks, everywhere |

World and weapon accents (`WorldData.accent_color`, `WeaponData.tracer_color`) colour
content, never chrome.

## Type

Two fonts: **Lilita One** (display: anything that reads as a sign) and **Baloo 2** (body).

| Constant | Size | Use |
| --- | --- | --- |
| `UiKit.SIZE_HERO` | 96 | One per screen at most (the home PLAY button, a result) |
| `UiKit.SIZE_TITLE` | 64 | The name on a signboard |
| `UiKit.SIZE_HEADING` | 44 | Panel headings |
| `UiKit.SIZE_BUTTON` | 36 | Buttons |
| `UiKit.SIZE_LABEL` | 26 | Captions, section headers, stat names |
| `UiKit.SIZE_BODY` | 24 | Body text |
| `UiKit.SIZE_SMALL` | 20 | Notes. Nothing smaller: half the players see this at 720p |

```gdscript
UiKit.sign_label("ION CARBINE", UiKit.SIZE_TITLE)   # cream sign lettering, dark outline
UiKit.arcade_label("WAVE 3", 72)                    # white, heavy outline: over 3D and key art
UiKit.label("Sustained fire", UiKit.SIZE_LABEL, UiKit.CREAM)
UiKit.body("Long text that wraps.", 600)            # wraps inside 600 px
UiKit.section("STATS", "optional note")             # cyan caption + hairline
```

Display text is UPPERCASE; body text is sentence case.

## Spacing

`UiKit.GAP_XS` 4, `GAP_S` 8, `GAP_M` 16, `GAP_L` 24, `GAP_XL` 40; `UiKit.PAGE_MARGIN` 48
from the screen edge. Use these for container separations; do not invent values.

## Components

### Buttons

```gdscript
var deploy := UiKit.sign_button("DEPLOY")                               # pink: THE action
var arsenal := UiKit.sign_button("OPEN ARSENAL", SignButton.Kind.SECONDARY)   # teal
var buy := UiKit.sign_button("BUY", SignButton.Kind.GOLD)               # gold: spend Sparks, claim
var more := UiKit.sign_button("DETAILS", SignButton.Kind.NEUTRAL)       # purple: quiet
var back := UiKit.back_button()                                         # the BACK sign
var gear := UiKit.icon_button(&"icon_gear", "Settings")                 # 64 px, with a tooltip
var on_off := UiKit.toggle_button("ON", group)                          # purple off, pink on
deploy.pressed.connect(_deploy)
```

`UiKit.button()` and `UiKit.soft_button()` (older names) return the pink and teal sign
buttons. Every `SignButton` grows 4% and sends a shine across on hover **or keyboard
focus**, squashes when pressed, shows the focus ring (warm white with an amber glow, so it
is never mistaken for the cyan of a selection), greys out when `disabled`, and plays its
own sounds. One pink button per screen.

Icons in `art/ui`: `icon_spark`, `icon_lock`, `icon_gear`, `icon_power`, `icon_home`,
`icon_play`, `icon_film`, `icon_tutorial`, `icon_arrow_left/right`, `icon_check`,
`icon_close`, `icon_star`, `icon_star_empty`, `icon_mouse_l/r`.
`UiKit.icon(&"icon_lock", 32.0)` gives a `TextureRect`.

### Panels

```gdscript
var board := UiKit.signboard()        # cream trim: information (details, stats, forms)
var tray := UiKit.metal_frame()       # riveted teal frame, dark recess: grids, trays, lists
var plate := UiKit.metal_plate()      # solid teal plate: bars, plaques
var glow := UiKit.neon_panel(UiKit.PINK)   # dark plate, neon outline: callouts
var tile := UiKit.card_panel()        # dark tile: a stat or row inside another panel
board.add_child(my_vbox)              # panels are PanelContainers: one child
board.set_padding(24, 20)             # optional
```

`UiKit.box(fill, border, radius, border_width, padding)` still makes a flat rounded box
for tiny inner pieces; do not build panels from it.

### Marquee sign, slot plates, chips

```gdscript
var title := UiKit.marquee("ARSENAL")                 # bulbs chase by themselves
title.flash()                                         # all bulbs on for a moment
var slot := UiKit.slot_plate("PRIMARY [1]", "ION CARBINE")   # cyan = active
slot.active = false                                   # cream outline
slot.set_value("PULSE PISTOL")                        # pops when it changes
slot.set_note("Pistol · Rank 2")
row.add_child(UiKit.chip("AUTO · RANK 3"))            # pointed chip (28 px on a signboard)
row.add_child(UiKit.chip("NEW", UiKit.PINK, 18, false))   # pill
```

The shell draws the page's marquee; pages do not add their own.

### Item cards

```gdscript
var group := ButtonGroup.new()
var card := UiKit.item_card("ION CARBINE", Vector2(220, 250))
card.button_group = group
card.set_image(thumbnail)            # any Texture2D; set_preview(control) for a live view
card.set_status("Carbine")           # plain line under the name
card.set_locked("Lv 5")              # padlock + requirement, picture dimmed
card.set_price(450, Wallet.can_afford(450))   # Spark icon + price (red if too dear)
card.set_tag("EQUIPPED")             # corner tag
card.set_new(true)                   # NEW badge
card.set_rarity(rarity_colour)       # line under the picture
card.selected = true                 # cyan outline (one per group)
card.pressed.connect(_select.bind(item))
```

States: normal, hover (lighter rim, +3.5%), focus (warm white ring), selected (cyan
outline and glow), locked (dim picture, amber padlock line). Cards go in a `metal_frame()`.

### Stats, bars, tabs

```gdscript
var dps := UiKit.stat_row("DPS", "131")
var reach := UiKit.stat_row("RANGE", "", true)        # with a bar
reach.set_value("36 m", 0.6)                          # animates when visible
var xp := UiKit.progress(0.45, 18.0, UiKit.AMBER)     # a ProgressBar
UiFx.fill_to(xp, 0.8)

var tabs := UiKit.tabs()
tabs.add_tab(&"mastery", "WEAPON MASTERY")
tabs.add_tab(&"challenges", "CHALLENGES", 3)          # count badge
tabs.tab_changed.connect(_show_tab)
tabs.step(1)                                          # bind to a shoulder button
```

### Player, Sparks, prompts

```gdscript
bar.add_child(UiKit.level_badge())            # follows Progression
bar.add_child(UiKit.sparks_chip())            # follows Wallet, counts up on change
row.add_child(UiKit.price_tag(450))           # Spark + amount, for prices and rewards
row.add_child(UiKit.spark_icon(32.0))
row.add_child(UiKit.key_prompt("ESC", "Back"))    # "LMB" / "RMB" draw a mouse
```

Sparks are always the gold four-point star with a cyan glow and gold numbers; amounts go
through `Wallet.format()`.

### Scrolling, tooltips, toasts, dialogs

```gdscript
var scroll := UiKit.scroll(Vector2(0, 420))   # styled bar, follows keyboard focus
UiKit.tooltip(button, "What this does")
UiKit.toast("Loadout saved")
UiKit.toast("Not enough Sparks", UiKit.RED)
UiKit.toast("450 Sparks banked", Wallet.COLOR, &"icon_spark")
UiKit.confirm(self, "BUY COMET TRAIL?", "450 Sparks", "BUY", _buy)   # modal; Esc cancels
KitDialog.notice(self, "SAVED", "Your settings were saved.")
```

## Motion

All motion comes from `UiFx`; it is tween based and nothing runs once it has finished.

| Call | When |
| --- | --- |
| `UiFx.page_in(page, dir)` / `page_out` | Page changes (the shell does this) |
| `UiFx.stagger_in(items)` | A list or grid appears: items pop in 30 ms apart |
| `UiFx.pop_in(c)` | One thing appears (a dialog, a toast, a reward) |
| `UiFx.hover(c, on)`, `UiFx.squash(c)` | Hover / press on custom controls (kit buttons do it themselves) |
| `UiFx.pulse(c)` | A value changed, a reward landed |
| `UiFx.deny(c)` | Refused: shake + the deny sound |
| `UiFx.count_up(label, from, to)` | Numbers: scores, Sparks, XP |
| `UiFx.fill_to(bar, value)` | Bars |

Rules: a page change takes `UiFx.PAGE` (0.24 s) or less; hover and focus react within
`UiFx.FAST` (0.1 s); a staggered list starts its last item within 0.3 s; animate only
scale, alpha and position of non-container children, never layout. No `_process` that
redraws while idle: redraw from signals, timers (the marquee bulbs step at 6 Hz) or tweens.

## Sound

`UiSound.hover() / click() / back() / tab() / select() / equip() / deny() / confirm() /
open() / toast() / tick() / purchase() / sparks() / page()`. Kit components already play
theirs; call these only for your own interactions (`UiSound.equip()` after equipping,
`UiSound.purchase()` after `Cosmetics.buy()`).

## Focus and navigation

Everything interactive must be reachable without a mouse. Kit controls are focusable and
show the focus ring. Name the control that should start with focus `FirstFocus` (or
override `first_focus()`); keep neighbours in reading order (containers do this for you);
use `UiKit.scroll()` so focus scrolls lists. In the menu, Esc / BACK goes back, Q / E
(PageUp / PageDown, shoulder buttons) step through the sections of the top bar.

## A page in the shell

Register the page with a `UiExtension` resource in `data/ui/` (kind `MENU_PAGE`): its
`title` is the tab and the marquee, `order` places the tab (Arsenal 40, Locker 50, Shop
55, Career 60), and the shell opens it by `id`.

```gdscript
class_name ShopPage
extends MenuPage

func uses_shell_header() -> bool:
	return true                      # the shell draws BACK + the marquee; I draw content

func header_extra() -> Control:      # optional: right of the marquee (tabs, plates, counters)
	return _tabs

func _ready() -> void:
	# My rectangle is the content area: under the header row, inside the page margins.
	var row := HBoxContainer.new()
	row.set_anchors_and_offsets_preset(Control.PRESET_FULL_RECT)
	row.add_theme_constant_override("separation", UiKit.GAP_L)
	add_child(row)
	var tray := UiKit.metal_frame()
	tray.size_flags_horizontal = Control.SIZE_EXPAND_FILL
	row.add_child(tray)
	row.add_child(UiKit.signboard())

func refresh() -> void:              # every time the page is shown
	UiFx.stagger_in(_grid.get_children())

func handle_back() -> bool:          # optional: close a sub-view first
	return false

func first_focus() -> Control:
	return _first_card
```

| The shell draws | The page draws |
| --- | --- |
| The live world behind (or the page's `backdrop()`, a full-screen Control such as the Arsenal booth) | Its content, in the rectangle it is given |
| Top bar: home, tabs, level and title, Sparks, settings, quit | Extra header controls through `header_extra()` |
| Header row: BACK sign, marquee with the page title | Sub-views and their back step (`handle_back()`) |
| Page transition, Esc / BACK, Q / E, initial focus, toasts | Its own stagger-in on `refresh()` |

At 1920x1080 the content rectangle is 1824 x 840 (taller on 16:10). `MenuPage.TOP_BAR`
and `MenuPage.HEADER` are the heights of the two shell rows. To open another page emit
`open_page(&"locker")`; BACK then returns to yours. A page that returns false from
`uses_shell_header()` (the default) is treated as a page from before the shell: it keeps
its own title and BACK and is scaled to fit under the top bar.

## Do / don't

* **Do** give every screen exactly one pink button, and put it where the eye ends up.
* **Do** put information on signboards, collections in metal frames, state on chips.
* **Do** show a lock as padlock + what unlocks it ("Lv 5"), never as a bare grey card.
* **Do** test at 960x540 and in a 16:10 window; text must still read.
* **Don't** draw flat navy panels with a pink outline (the old look) or hand-made
  `StyleBoxFlat` buttons.
* **Don't** use more than two accent colours inside one panel.
* **Don't** put body text straight on the 3D world: use a panel or `arcade_label`.
* **Don't** rebuild layouts or allocate every frame; update labels when data changes.
* **Don't** add a texture by hand: add it to `tools/gen_ui_textures.py` and `KitTex.SPECS`.
